# useable pay v1.0

A mobile money quick-pay app for Zambia - MTN MoMo & Airtel Money

## How to use
1. Open index.html in your browser, or deploy to GitHub Pages
2. Add stores with name, network, and agent/till number
3. Tap Pay → Enter amount + PIN → Dial Now

## Features
- Supports MTN MoMo: *115*1*1*Agent*Amount#
- Supports Airtel Money: *115*8*Till*Amount#
- All data stored locally on your phone
- PIN is never stored

## Deploy to GitHub Pages
1. Create new repo, upload index.html
2. Settings → Pages → Deploy from main branch
3. Open the URL → Add to Home Screen
